VaultCore Financial – Frontend is a secure, modular, and interactive Neo-Banking user interface built to simulate real-world banking workflows. Developed with React (Vite), it provides responsive pages, dynamic dashboards, and secure user interactions while integrating seamlessly with a production-grade backend. The frontend implements login authentication, a multi-step money transfer wizard, and a portfolio dashboard with real-time visualizations using Recharts, all designed to ensure usability, consistency, and security.

🛠 Tech Stack

React (Vite) – Modern frontend framework

React Router – Page navigation

Axios – Secure API calls

Recharts – Portfolio & transaction visualization

CSS (custom styling) – Responsive UI design


🟦 Week-wise Frontend Implementation Highlights

Week 1: Secure login page with JWT stored securely in local storage.

Week 2: Multi-step “Send Money” wizard with client-side validations.

Week 3: Portfolio dashboard displaying stock values and latency using Recharts.

Week 4: UI integration for audit logging feedback and PDF statements download.

▶️ Running the Frontend
# Navigate to frontend folder
cd VaultCore_Financial_FE

# Install dependencies
npm install

# Start development server
npm run dev


Open http://localhost:5173 (default Vite port) to interact with the application.
